CraftPull

Release manager for GitHub repositories.

What it does

CraftPull watches your repositories, downloads new release files, verifies their SHA-256 checksums and removes outdated versions — pinned versions stay untouched.

Installation

The application will be installed in /Applications. Open it from there or from Spotlight.

CraftPull — менеджер релизов для репозиториев GitHub. Следит за новыми релизами, скачивает файлы, проверяет их контрольные суммы SHA-256 и удаляет устаревшие версии — закреплённые версии остаются нетронутыми. Программа будет установлена в папку /Applications.
