Куда открывать подробности репозитория

Сетка карточек становится режимом по умолчанию. При клике по карточке нужно показать подробности и кнопку «Скачать». Ниже — три реализуемых в egui варианта: как именно карточка «переезжает» и где живёт детальная информация.

Плюсы

  • Детали всегда на виду, «Скачать» — в один клик
  • Выбор сохраняется: можно листать карточки, панель обновляется
  • Сетка не перекрывается, ничего не прыгает
  • Привычная схема master-detail, легко масштабируется

Минусы

  • Сетка сужается: 5 колонок → 3–4
  • Панель занимает ~340 px постоянно, пока открыта
  • На узком окне (<1000 px) придётся скрывать или прятать

Анимация: ширина панели — одно число, плавно интерполируемое к 0 или 340 px (ctx.animate_bool_with_time + request_repaint). Выбранная карточка получает акцентную рамку и плавно увеличивается scale 1.0 → 1.045 за 200 мс. Реализуемо целиком в egui.

Плюсы

  • Карточка буквально «переезжает» — как вы и просили
  • Место не теряется: сетка остаётся в кадре
  • Фокус на одном репозитории, без затемнения

Минусы

  • Плитки ниже уезжают вниз — контент прыгает
  • В egui Grid высоту ячейки не анимировать: прыжок будет рывком
  • На узком окне герой-карточка слишком широкая

Анимация: высоту героя можно интерполировать вручную (собственный Vec с плавными значениями), но egui::Grid пересчитывает строки по фактической высоте — плавного «разъезда» соседних плиток не получится, будет ступенчатое перетекание.

Общее для всех вариантов: отметка репозиториев

Сейчас отметить репозиторий можно только в настройках

В сетке и в списке нет чекбоксов — есть только надпись «not selected». Если карточки становятся основным режимом, выбор должен происходить прямо на карточке, иначе придётся каждый раз прыгать во вкладку «Настройки».

чекбокс в углу карточки клик по телу карточки — детали Select all / Clear selection остаются фильтр файлов — в панели деталей

Бонус: фильтр файлов (Portable / All / Source) сейчас тоже живёт только в настройках. Если перенести его в панель деталей, настройки превратятся в «глобальные параметры», а выбор репозиториев — в повседневную работу. Это отдельное решение, скажите, если брать.
